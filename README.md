# Pembuat Rencana Belajar Website satu halaman: pengguna mengisi topik, waktu per hari, target, dan level; AI menyusun jadwal belajar harian dalam bentuk tabel. ## Struktur- `index.html` : form, tabel hasil, tombol Salin dan Cetak- `netlify/functions/generate.js` : memanggil Claude API (API key tetap di server)- `netlify.toml` : konfigurasi Netlify ## Menjalankan1. `npm i -g netlify-cli`2. Buat file `.env` berisi `ANTHROPIC_API_KEY=isi_key_kamu` (jangan di-commit)3. `netlify dev` lalu buka http://localhost:8888 ## DeployHubungkan repo ke Netlify, tambahkan `ANTHROPIC_API_KEY` di Site settings > Environment variables.
